# anatomy3d 项目书

> 版本 v1.0（2026-11-23）· 状态：M0 框架底座交付 · 决策依据：可行性分析（2026-11-23，结论「推荐立项」）

---

## 一、项目定位

**一句话**：基于开放解剖数据的离线人体解剖 3D 教育查看器 —— 看（浏览）、剥（分层透视）、学（标注与测验）。

- **目标用户**：医学生、解剖学学习者、科普内容创作者。
- **差异化**：商业产品（Complete Anatomy / BioDigital / Visible Body 等）全部收费或订阅；开放生态里 Z-Anatomy 本体绑定 Blender 才能交互。本项目的空档 = **独立离线程序 + 中文本地化 + 开放数据**。
- **用途边界**：教学用途，非临床（开放数据精度边界决定，UI 明示）。

## 二、可行性结论（调研依据摘要）

三维支撑，详见调研时点 2026-11-23：

1. **渲染层复用率高**：既有 3dworld 引擎已具备 glTF 2.0/GLB 加载（含蒙皮）、射线拾取、Weighted Blended OIT（器官半透明透视的关键件）、CJK 字体、PBR/CSM/后处理。缺口仅「剖面裁剪」（自研 shader clip plane）与「大网格性能治理」。
2. **数据零采购成本**：Z-Anatomy（CC BY-SA 4.0，数千结构含肌肉起止点）、BodyParts3D 4.3（3210 验证网格，CC BY-SA 2.1 JP）、TA2 术语标准（免费）。
3. **管线先例充分**：社区项目 Anatria-3D 已走通 Z-Anatomy → Blender 无头导出 → 按系统 GLB → 自研查看器全链路（13 系统 / 3478 结构 / 8.6M 三角形 / 37MB），且公开全部工程坑点（已固化到 tools/pipeline/README.md）。

## 三、系统架构

```
┌──────────────────────────────────────────────────────────┐
│                     anatomy3d 独立仓                       │
│                                                          │
│  data/            Z-Anatomy .blend（外部，gitignore）     │
│      ↓ M1 资产管线（Blender 无头导出）                     │
│  assets/          按系统 GLB + manifest.json              │
│      ↓ structure-manifest v1 契约（anatomy3d/contracts）  │
│  anatomy3d/viewer    GLB 加载·拾取·显隐·OIT·标注（M2）     │
│  anatomy3d/knowledge TA2 三语索引·定义·quiz（M3/M4）      │
│      ↓                                                  │
│  selfcheck.py / tests   无头门禁                          │
└──────────────────────────────────────────────────────────┘
```

**契约纪律**（沿用组合仓四条核心纪律中的可迁移项）：
- `structure-manifest v1` 独立版本化：资产包版本与查看器版本解耦，未来换/升级数据源不动代码；
- 零依赖 Protocol 层：`contracts/` 不 import 任何实现模块；
- 3dworld 引擎复用采用「对接面 Protocol + 环境变量注入」，不 vendor、不 fork。

## 六、许可合规

- **代码**：MIT（LICENSE）。
- **数据**：Z-Anatomy CC BY-SA 4.0 / BodyParts3D CC BY-SA 2.1 JP —— share-alike 约束下，衍生模型数据必须继续开源并署名；本仓以 **NOTICE 双轨授权**落地（代码 MIT ≠ 数据 CC BY-SA）。
- **术语**：TA2（FIPAT）免费使用；中文映射用《人体解剖学名词》对照，注明来源。
- **署名时点纪律**：NOTICE 先登记计划引入的数据源与许可，数据入库当天即生效，不留合规空窗。
